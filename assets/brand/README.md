# CloudLibrary Brand Assets

CloudLibrary's mark is a book-cloud: three book spines tucked under a cloud arch, with a rust bookmark that also hints at a lending slip. It should feel warm, personal, and quietly trustworthy rather than corporate.

## Files

- `cloudlibrary-mark.svg` - square app icon / avatar / favicon source.
- `cloudlibrary-wordmark.svg` - primary horizontal lockup for light backgrounds.
- `cloudlibrary-wordmark-reverse.svg` - horizontal lockup for dark backgrounds.
- `cloudlibrary-lockup-stacked.svg` - stacked lockup for centered placements.

## Palette

- Paper: `#f6efe0`
- Ink: `#0f1813`
- Deep green: `#2b4638`
- Shelf green: `#4a7460`
- Soft green: `#93b09c`
- Rust: `#b5563a`
- Gold: `#e6c765`

## Typography

- Wordmark: Fraunces, semi-bold, with `Library` in italic rust.
- Supporting UI: Archivo.
- Small labels: IBM Plex Mono or Archivo in uppercase.

## Usage Notes

Keep generous spacing around the icon. For tiny sizes, use the mark alone; for headers, use the horizontal wordmark. The reverse version is tuned for the app's current dark ink background.
